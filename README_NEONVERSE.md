# NEONVERSE --- Immersive Digital Worlds Landing Page

## Project Overview

NEONVERSE is a fictional immersive digital-experience studio. This
landing page introduces the studio and showcases its creative worlds,
interactive experiences, and digital-art direction.

The design is intended to make visitors curious about the studio and
encourage them to explore its featured worlds or get in touch.

## Target Audience

-   People interested in immersive digital experiences and virtual
    worlds
-   Creative professionals, designers, and digital-art enthusiasts
-   Brands or clients looking for interactive storytelling and
    digital-experience design

## Main Sections

### 1. Header / Navigation

-   NEONVERSE logo
-   Experience, Worlds, and Studio navigation links
-   "Enter the Lab" call-to-action

### 2. Hero Section

-   Main headline: "Step Beyond the Screen."
-   Short introduction to the studio
-   "Explore Worlds" primary button
-   "Watch the Reel" secondary action
-   Featured-world artwork and supporting visual cards

### 3. Studio Statistics

-   Worlds launched
-   Average rating

### 4. Selected Experiences

A horizontal list highlighting featured experiences: - Beyond Zero -
Lucid City - Soft Machines

### 5. About the Studio

A short brand statement describing the studio's vision: "The future you
can enter, shape, and make your own."

### 6. Footer

-   NEONVERSE brand mark
-   Contact prompt and email address
-   Closing brand information

## Design Choices

### Visual Direction

The interface uses a dark, atmospheric visual style to create a
futuristic and immersive mood. A subtle grid gives the page structure,
while glowing gradients and vivid artwork add depth.

### Color Palette

  Color                      Hex         Usage
  -------------------------- ----------- -----------------------------
  Deep violet / near black   `#090513`   Main background
  Dark purple                `#1B0828`   Atmospheric gradient areas
  Teal                       `#22DCCB`   Accent and highlighted text
  Magenta                    `#F34DB8`   Accent details
  Off-white                  `#F5F1FA`   Main text
  Muted lavender             `#A79BB4`   Secondary text

### Typography

A modern sans-serif typeface is used throughout. Large uppercase
headlines create a strong visual hierarchy, while smaller letter-spaced
labels and muted body text support readability.

### Layout and Spacing

-   A wide desktop layout places the main message on the left and
    featured artwork on the right.
-   Clear spacing separates the hero, experience list, studio statement,
    and footer.
-   Thin dividers and a subtle background grid help organize the content
    without making it feel crowded.
